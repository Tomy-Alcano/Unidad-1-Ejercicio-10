# Unidad-1-Ejercicio-10
Programacion 3 Unidad 1 - Ejercicio 10
Ejercicio 10 — Diseño libre: tu propia aplicación
Este último ejercicio es diferente a los anteriores: no hay una consigna cerrada. El objetivo es que apliques de forma autónoma todo lo aprendido en la unidad para diseñar y construir una ventana de tu propia elección.

Pensá en una aplicación que te resulte interesante o útil: puede ser una pantalla de registro para un sistema de turnos, una ficha de un videojuego, un formulario de reserva de hotel, una pantalla de configuración de una app, o cualquier otra idea que se te ocurra.

Tu aplicación debe cumplir con los siguientes requisitos mínimos:

Utilizar al menos un JFrame correctamente configurado (título, tamaño, cierre, centrado)
Organizar los componentes en al menos dos JPanel con roles distintos
Incluir al menos cuatro tipos de componentes diferentes entre los vistos en la unidad (JLabel, JTextField, JButton, JCheckBox, JRadioButton, JComboBox)
Al menos un componente debe tener un estado inicial configurado (deshabilitado, desmarcado, con texto predefinido, etc.)
El método main debe estar estructurado correctamente con SwingUtilities.invokeLater
Junto con el código, escribí un breve párrafo (entre 5 y 10 líneas) explicando qué aplicación decidiste construir, qué componentes utilizaste y por qué los elegiste para ese caso.

💡 Este ejercicio no tiene una solución única correcta. Se evaluará la coherencia entre la idea elegida, los componentes utilizados y la organización visual de la interfaz.
